PART 0 — The big picture (read this first)

0.1 How a modern web app works

┌──────────────────────┐        HTTPS + JSON         ┌───────────────────────┐        SQL        ┌──────────────┐
│  Browser              │ ─────────────────────────▶ │  ASP.NET Core Web API │ ────────────────▶ │  SQL Server  │
│  Angular or React SPA │ ◀───────────────────────── │  (stateless)          │ ◀──────────────── │  ProductHubDB│
└──────────────────────┘   Authorization: Bearer JWT └───────────────────────┘    EF Core        └──────────────┘
   localhost:4200 (Ng)                                   localhost:7001
   localhost:5173 (React)

Key terms:

  • SPA (Single Page Application): the browser downloads the app once. After that, it only exchanges JSON with the API, never full HTML pages. Angular and React both build SPAs.
  • REST API: URLs name resources (/api/products/5), and HTTP verbs say what to do with them (GET read, POST create, PUT update, DELETE remove).
  • Stateless: the API remembers nothing between requests. Each request proves who the user is by carrying a JWT in the Authorization header.
  • CORS: browsers block calls from one origin (localhost:4200) to another (localhost:7001) unless the API explicitly allows that origin.

0.4 The three other flows you'll implement

Login

Login form → POST /api/auth/login { email, password }
API: find user → check hashed password (lockout after 5 failures) → create JWT (15 min)
     + refresh token (7 days, stored HASHED in DB)
Client stores { accessToken, refreshToken, user } → shows the user's name, Admin buttons, etc.

Silent token refresh (when the access token expires)

Any request → 401 (token expired)
Interceptor catches the 401 → POST /api/auth/refresh { refreshToken }
API: old refresh token revoked → new pair issued ("rotation")
Interceptor saves the new tokens → retries the original request → the user notices nothing
If refresh fails → clear tokens → redirect to /login

Image upload (two-step, keeps the product save as plain JSON)

User picks a file → POST /api/products/upload (multipart, field "file")
API validates type/size → saves wwwroot/images/{guid}.jpg → returns { fileName, url }
Client puts fileName into the form's hidden "imageFileName" field and shows the preview from url
On Save, the product JSON includes imageFileName → stored in Products.ImageUrl

PART 1 — The API (ASP.NET Core)

1.0 Concepts for this part

  • Code First vs Database First. In Database First (your exam), you write SQL and EF generates classes. In Code First, you write C# classes and EF generates the database through migrations. Most teams use Code First for new projects, because the schema lives in source control and evolves through reviewable migration files. Database First is mainly used when the database already exists.
  • Layering: Controller (HTTP) → Service (business logic) → DbContext (data). Each layer has one job, which makes the code easy to change and test.
  • DTOs (Data Transfer Objects): the shapes the API sends and receives. Entities never leave the API, which prevents serialization loops, hides internal columns, and lets the database change without breaking clients.
  • Dependency Injection (DI): classes ask for what they need in their constructor (ProductService(AppDbContext db, ...)), and ASP.NET Core provides it. You register services once, in Program.cs.
  • Async everywhere: every database call is awaited. While SQL Server works, the thread serves other requests.

1.5 The DbContext

Data/AppDbContext.cs

using Microsoft.AspNetCore.Identity.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore;
using ProductApi.Entities;

namespace ProductApi.Data;

// IdentityDbContext adds the AspNetUsers, AspNetRoles, ... tables to the same database
public class AppDbContext(DbContextOptions<AppDbContext> options) : IdentityDbContext<AppUser>(options)
{
    public DbSet<Category> Categories => Set<Category>();
    public DbSet<Product> Products => Set<Product>();
    public DbSet<Brand> Brands => Set<Brand>();
    public DbSet<RefreshToken> RefreshTokens => Set<RefreshToken>();

    protected override void OnModelCreating(ModelBuilder builder)
    {
        base.OnModelCreating(builder);   // required for Identity

        builder.Entity<Category>(e =>
        {
            e.Property(c => c.CategoryName).HasMaxLength(100).IsRequired();
            e.HasIndex(c => c.CategoryName).IsUnique();
            e.HasData(                                   // seed data, inserted by the migration
                new Category { CategoryId = 1, CategoryName = "Electronics" },
                new Category { CategoryId = 2, CategoryName = "Clothing" },
                new Category { CategoryId = 3, CategoryName = "Food" });
        });

        builder.Entity<Product>(e =>
        {
            e.Property(p => p.ProductName).HasMaxLength(100).IsRequired();
            e.Property(p => p.ManufacturingDate).HasColumnType("datetime");
            e.Property(p => p.SerialNo).HasMaxLength(50).IsRequired();
            e.Property(p => p.ImageUrl).HasMaxLength(200).IsRequired();
            e.Property(p => p.Price).HasPrecision(18, 2);
            e.HasIndex(p => p.SerialNo).IsUnique();      // no two products with the same serial
            e.HasOne(p => p.Category)
             .WithMany(c => c.Products)
             .HasForeignKey(p => p.CategoryId)
             .OnDelete(DeleteBehavior.Restrict);         // can't delete a category that has products
        });

        builder.Entity<Brand>(e =>
        {
            e.Property(b => b.BrandName).HasMaxLength(100).IsRequired();
            e.HasOne(b => b.Product)
             .WithMany(p => p.Brands)
             .HasForeignKey(b => b.ProductId)
             .OnDelete(DeleteBehavior.Cascade);          // ON DELETE CASCADE, as in your schema
        });

        builder.Entity<RefreshToken>(e =>
        {
            e.Property(t => t.TokenHash).HasMaxLength(128).IsRequired();
            e.HasIndex(t => t.TokenHash).IsUnique();
            e.HasOne(t => t.User)
             .WithMany(u => u.RefreshTokens)
             .HasForeignKey(t => t.UserId)
             .OnDelete(DeleteBehavior.Cascade);
        });
    }
}

This Fluent API configuration produces exactly your SQL schema: the lengths, DECIMAL(18,2), DATETIME, the foreign keys and the cascade. In bigger projects, each entity's configuration usually moves into its own IEntityTypeConfiguration<T> class.

1.8 Services (business logic)

Services/ImageService.cs

using ProductApi.Common;
using ProductApi.Dtos;

namespace ProductApi.Services;

public interface IImageService
{
    Task<UploadResponse> SaveAsync(IFormFile file, CancellationToken ct);
    void Delete(string? fileName);
    string GetUrl(string? fileName);
}

public class ImageService(IWebHostEnvironment env, IHttpContextAccessor httpContextAccessor) : IImageService
{
    public const string DefaultImage = "noimage.png";
    private const long MaxBytes = 2 * 1024 * 1024; // 2 MB
    private static readonly string[] AllowedExtensions = [".jpg", ".jpeg", ".png", ".webp"];

    private string ImageFolder => Path.Combine(env.WebRootPath, "images");

    public async Task<UploadResponse> SaveAsync(IFormFile file, CancellationToken ct)
    {
        if (file.Length == 0) throw new BadRequestException("The file is empty.");
        if (file.Length > MaxBytes) throw new BadRequestException("Maximum image size is 2 MB.");

        var extension = Path.GetExtension(file.FileName).ToLowerInvariant();
        if (!AllowedExtensions.Contains(extension) || !file.ContentType.StartsWith("image/"))
            throw new BadRequestException("Only .jpg, .jpeg, .png and .webp images are allowed.");

        Directory.CreateDirectory(ImageFolder);
        // Never use the client's file name: a random name prevents overwrites and path tricks like "../../web.config"
        var fileName = $"{Guid.NewGuid()}{extension}";
        await using var stream = new FileStream(Path.Combine(ImageFolder, fileName), FileMode.Create);
        await file.CopyToAsync(stream, ct);

        return new UploadResponse(fileName, GetUrl(fileName));
    }

    public void Delete(string? fileName)
    {
        if (string.IsNullOrWhiteSpace(fileName) || fileName == DefaultImage) return;
        var path = Path.Combine(ImageFolder, Path.GetFileName(fileName));
        if (File.Exists(path)) File.Delete(path);
    }

    public string GetUrl(string? fileName)
    {
        var name = string.IsNullOrWhiteSpace(fileName) ? DefaultImage : fileName;
        var request = httpContextAccessor.HttpContext?.Request;
        return request is null ? $"/images/{name}" : $"{request.Scheme}://{request.Host}/images/{name}";
    }
}

{
    private readonly JwtOptions _jwt = options.Value;

    public AccessToken CreateAccessToken(AppUser user, IEnumerable<string> roles)
    {
        // Claims = facts about the user, readable by anyone who has the token (never put secrets here)
        var claims = new List<Claim>
        {
            new(JwtRegisteredClaimNames.Sub, user.Id),
            new(JwtRegisteredClaimNames.Email, user.Email ?? string.Empty),
            new("name", user.FullName),
            new(JwtRegisteredClaimNames.Jti, Guid.NewGuid().ToString())
        };
        claims.AddRange(roles.Select(role => new Claim("role", role)));

        var expiresAt = DateTime.UtcNow.AddMinutes(_jwt.AccessTokenMinutes);
        var signingKey = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(_jwt.Key));

        var token = new JsonWebTokenHandler().CreateToken(new SecurityTokenDescriptor
        {
            Subject = new ClaimsIdentity(claims),
            Expires = expiresAt,
            Issuer = _jwt.Issuer,
            Audience = _jwt.Audience,
            SigningCredentials = new SigningCredentials(signingKey, SecurityAlgorithms.HmacSha256)
        });

        return new AccessToken(token, expiresAt);
    }

    public (string RawToken, string TokenHash) CreateRefreshToken()
    {
        var raw = Convert.ToBase64String(RandomNumberGenerator.GetBytes(64));
        return (raw, HashToken(raw));
    }

    public string HashToken(string rawToken) =>
        Convert.ToHexString(SHA256.HashData(Encoding.UTF8.GetBytes(rawToken)));
}

What a JWT is. A JWT is three Base64 parts: header.payload.signature. The payload (the claims) is readable by anyone; paste a token into jwt.io to see. The signature proves the API created it and that nobody changed it. That's why the signing key must stay secret.

using Microsoft.AspNetCore.Identity;
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Options;
using ProductApi.Common;
using ProductApi.Data;
using ProductApi.Dtos;
using ProductApi.Entities;

namespace ProductApi.Services;

public interface IAuthService
{
    Task<AuthResponse> RegisterAsync(RegisterRequest request, CancellationToken ct);
    Task<AuthResponse> LoginAsync(LoginRequest request, CancellationToken ct);
    Task<AuthResponse> RefreshAsync(string refreshToken, CancellationToken ct);
    Task LogoutAsync(string userId, string refreshToken, CancellationToken ct);
    Task<UserDto?> GetUserAsync(string userId);
}

public class AuthService(
    UserManager<AppUser> userManager,
    SignInManager<AppUser> signInManager,
    AppDbContext db,
    ITokenService tokenService,
    IOptions<JwtOptions> jwtOptions,
    ILogger<AuthService> logger) : IAuthService
{
    private readonly JwtOptions _jwt = jwtOptions.Value;

    public async Task<AuthResponse> RegisterAsync(RegisterRequest request, CancellationToken ct)
    {
        if (await userManager.FindByEmailAsync(request.Email) is not null)
            throw new ConflictException("An account with this email already exists.");

        var user = new AppUser { UserName = request.Email, Email = request.Email, FullName = request.FullName.Trim() };

        var result = await userManager.CreateAsync(user, request.Password);   // hashes the password
        if (!result.Succeeded)
            throw new BadRequestException(string.Join(" ", result.Errors.Select(e => e.Description)));

        await userManager.AddToRoleAsync(user, Roles.User);
        logger.LogInformation("User registered: {Email}", user.Email);
        return await IssueTokensAsync(user, ct);
    }

    public async Task<AuthResponse> LoginAsync(LoginRequest request, CancellationToken ct)
    {
        var user = await userManager.FindByEmailAsync(request.Email);
        // Same message for "unknown email" and "wrong password": attackers can't discover which emails exist
        if (user is null) throw new UnauthorizedException("Invalid email or password.");

        var result = await signInManager.CheckPasswordSignInAsync(user, request.Password, lockoutOnFailure: true);
        if (result.IsLockedOut) throw new UnauthorizedException("Account locked after too many attempts. Try again in 15 minutes.");
        if (!result.Succeeded) throw new UnauthorizedException("Invalid email or password.");

        return await IssueTokensAsync(user, ct);
    }

    public async Task<AuthResponse> RefreshAsync(string refreshToken, CancellationToken ct)
    {
        var hash = tokenService.HashToken(refreshToken);
        var stored = await db.RefreshTokens.Include(t => t.User).FirstOrDefaultAsync(t => t.TokenHash == hash, ct);

        if (stored is null) throw new UnauthorizedException("Invalid refresh token.");

        if (stored.RevokedAt is not null)
        {
            // A revoked token used again = probably stolen → end every session of this user
            logger.LogWarning("Refresh token reuse detected for user {UserId}", stored.UserId);
            await db.RefreshTokens
                .Where(t => t.UserId == stored.UserId && t.RevokedAt == null)
                .ExecuteUpdateAsync(s => s.SetProperty(t => t.RevokedAt, DateTime.UtcNow), ct);
            throw new UnauthorizedException("Session expired. Please log in again.");
        }

        if (stored.ExpiresAt <= DateTime.UtcNow) throw new UnauthorizedException("Session expired. Please log in again.");

        stored.RevokedAt = DateTime.UtcNow;   // ROTATION: each refresh token works exactly once
        return await IssueTokensAsync(stored.User, ct);
    }

    public async Task LogoutAsync(string userId, string refreshToken, CancellationToken ct)
    {
        var hash = tokenService.HashToken(refreshToken);
        var stored = await db.RefreshTokens.FirstOrDefaultAsync(t => t.TokenHash == hash && t.UserId == userId, ct);
        if (stored is { RevokedAt: null })
        {
            stored.RevokedAt = DateTime.UtcNow;
            await db.SaveChangesAsync(ct);
        }
    }

    public async Task<UserDto?> GetUserAsync(string userId)
    {
        var user = await userManager.FindByIdAsync(userId);
        if (user is null) return null;
        var roles = await userManager.GetRolesAsync(user);
        return new UserDto(user.Id, user.Email ?? string.Empty, user.FullName, roles.ToList());
    }

    private async Task<AuthResponse> IssueTokensAsync(AppUser user, CancellationToken ct)
    {
        var roles = await userManager.GetRolesAsync(user);
        var accessToken = tokenService.CreateAccessToken(user, roles);
        var (rawRefresh, refreshHash) = tokenService.CreateRefreshToken();
        var refreshExpiresAt = DateTime.UtcNow.AddDays(_jwt.RefreshTokenDays);

        db.RefreshTokens.Add(new RefreshToken
        {
            UserId = user.Id,
            TokenHash = refreshHash,
            CreatedAt = DateTime.UtcNow,
            ExpiresAt = refreshExpiresAt
        });
        await db.SaveChangesAsync(ct);   // also saves the revocation from RefreshAsync (same transaction)

        return new AuthResponse(accessToken.Token, accessToken.ExpiresAt, rawRefresh, refreshExpiresAt,
            new UserDto(user.Id, user.Email ?? string.Empty, user.FullName, roles.ToList()));
    }
}

Why two tokens?

  • Access token: short-lived (15 min), never stored by the API, checked on every request. It can't be cancelled, so it must expire quickly.
  • Refresh token: long-lived (7 days), stored in the database as a hash, and used only to get a new pair. It can be cancelled (logout, theft detected).

Together they give users long sessions with fast, stateless request checks.

using Microsoft.EntityFrameworkCore;
using ProductApi.Common;
using ProductApi.Data;
using ProductApi.Dtos;
using ProductApi.Entities;

namespace ProductApi.Services;

public interface IProductService
{
    Task<PagedResult<ProductResponse>> GetPagedAsync(ProductQuery query, CancellationToken ct);
    Task<ProductResponse?> GetByIdAsync(int id, CancellationToken ct);
    Task<ProductResponse> CreateAsync(ProductRequest request, CancellationToken ct);
    Task<ProductResponse?> UpdateAsync(int id, ProductRequest request, CancellationToken ct);
    Task<bool> DeleteAsync(int id, CancellationToken ct);
}

public class ProductService(AppDbContext db, IImageService images) : IProductService
{
    public async Task<PagedResult<ProductResponse>> GetPagedAsync(ProductQuery q, CancellationToken ct)
    {
        // IQueryable = a query being built; nothing runs in SQL until ToListAsync/CountAsync
        IQueryable<Product> query = db.Products.AsNoTracking()
            .Include(p => p.Category)
            .Include(p => p.Brands);

        if (!string.IsNullOrWhiteSpace(q.Search))
        {
            var search = q.Search.Trim();
            query = query.Where(p => p.ProductName.Contains(search) || p.SerialNo.Contains(search));
        }
        if (q.CategoryId.HasValue)
            query = query.Where(p => p.CategoryId == q.CategoryId.Value);

        var desc = string.Equals(q.SortDir, "desc", StringComparison.OrdinalIgnoreCase);
        query = q.SortBy?.ToLowerInvariant() switch
        {
            "price" => desc ? query.OrderByDescending(p => p.Price) : query.OrderBy(p => p.Price),
            "date" => desc ? query.OrderByDescending(p => p.ManufacturingDate) : query.OrderBy(p => p.ManufacturingDate),
            "name" => desc ? query.OrderByDescending(p => p.ProductName) : query.OrderBy(p => p.ProductName),
            _ => query.OrderByDescending(p => p.ProductId)   // newest first by default
        };

        var total = await query.CountAsync(ct);
        var items = await query
            .Skip((q.Page - 1) * q.PageSize)   // e.g. page 3, size 10 → skip 20
            .Take(q.PageSize)
            .AsSplitQuery()
            .ToListAsync(ct);

        return new PagedResult<ProductResponse>(items.Select(ToResponse).ToList(), q.Page, q.PageSize, total);
    }

    public async Task<ProductResponse?> GetByIdAsync(int id, CancellationToken ct)
    {
        var product = await db.Products.AsNoTracking()
            .Include(p => p.Category)
            .Include(p => p.Brands)
            .FirstOrDefaultAsync(p => p.ProductId == id, ct);
        return product is null ? null : ToResponse(product);
    }

    public async Task<ProductResponse> CreateAsync(ProductRequest r, CancellationToken ct)
    {
        await EnsureCategoryExistsAsync(r.CategoryId, ct);

        var product = new Product
        {
            ProductName = r.ProductName.Trim(),
            ManufacturingDate = r.ManufacturingDate!.Value.ToDateTime(TimeOnly.MinValue),
            SerialNo = r.SerialNo.Trim(),
            ImageUrl = string.IsNullOrWhiteSpace(r.ImageFileName) ? ImageService.DefaultImage : r.ImageFileName,
            IsAvailable = r.IsAvailable,
            CategoryId = r.CategoryId,
            Price = r.Price,
            Brands = r.Brands.Select(b => new Brand { BrandName = b.BrandName.Trim(), Stock = b.Stock }).ToList()
        };

        db.Products.Add(product);
        await db.SaveChangesAsync(ct);   // EF inserts the product AND its brands in one transaction
        return (await GetByIdAsync(product.ProductId, ct))!;
    }

    public async Task<ProductResponse?> UpdateAsync(int id, ProductRequest r, CancellationToken ct)
    {
        var product = await db.Products.Include(p => p.Brands).FirstOrDefaultAsync(p => p.ProductId == id, ct);
        if (product is null) return null;

        await EnsureCategoryExistsAsync(r.CategoryId, ct);

        var oldImage = product.ImageUrl;
        var newImage = string.IsNullOrWhiteSpace(r.ImageFileName) ? oldImage : r.ImageFileName;

        product.ProductName = r.ProductName.Trim();
        product.ManufacturingDate = r.ManufacturingDate!.Value.ToDateTime(TimeOnly.MinValue);
        product.SerialNo = r.SerialNo.Trim();
        product.ImageUrl = newImage;
        product.IsAvailable = r.IsAvailable;
        product.CategoryId = r.CategoryId;
        product.Price = r.Price;

        // Replace brands: removing them from the collection deletes them (required relationship = orphan delete)
        product.Brands.Clear();
        foreach (var b in r.Brands)
            product.Brands.Add(new Brand { BrandName = b.BrandName.Trim(), Stock = b.Stock });

        await db.SaveChangesAsync(ct);
        if (newImage != oldImage) images.Delete(oldImage);   // clean up the replaced file
        return await GetByIdAsync(id, ct);
    }

    public async Task<bool> DeleteAsync(int id, CancellationToken ct)
    {
        var product = await db.Products.FindAsync([id], ct);
        if (product is null) return false;

        db.Products.Remove(product);      // Brands deleted by ON DELETE CASCADE
        await db.SaveChangesAsync(ct);
        images.Delete(product.ImageUrl);
        return true;
    }

    private async Task EnsureCategoryExistsAsync(int categoryId, CancellationToken ct)
    {
        if (!await db.Categories.AnyAsync(c => c.CategoryId == categoryId, ct))
            throw new BadRequestException($"Category {categoryId} does not exist.");
    }

    private ProductResponse ToResponse(Product p) => new(
        p.ProductId,
        p.ProductName,
        DateOnly.FromDateTime(p.ManufacturingDate),
        p.SerialNo,
        p.ImageUrl,
        images.GetUrl(p.ImageUrl),
        p.IsAvailable,
        p.CategoryId,
        p.Category?.CategoryName ?? string.Empty,
        p.Price,
        p.Brands.Select(b => new BrandResponse(b.BrandId, b.BrandName, b.Stock)).ToList());
}

EF Core habits shown here:

  • AsNoTracking for read-only queries: faster, because EF doesn't watch the entities for changes.
  • Filter and page in SQL (Where, Skip, Take before ToListAsync), never in memory.
  • Load with Include, then change, then SaveChangesAsync. EF works out the needed INSERT, UPDATE and DELETE statements itself.

using Microsoft.AspNetCore.Diagnostics;
using Microsoft.AspNetCore.Mvc;
using Microsoft.Data.SqlClient;
using Microsoft.EntityFrameworkCore;
using ProductApi.Common;

namespace ProductApi.Infrastructure;

public class GlobalExceptionHandler(
    ILogger<GlobalExceptionHandler> logger,
    IProblemDetailsService problemDetailsService,
    IHostEnvironment env) : IExceptionHandler
{
    public async ValueTask<bool> TryHandleAsync(HttpContext httpContext, Exception exception, CancellationToken ct)
    {
        var (status, title, detail) = exception switch
        {
            BadRequestException e => (400, "Bad request", e.Message),
            UnauthorizedException e => (401, "Unauthorized", e.Message),
            ConflictException e => (409, "Conflict", e.Message),
            DbUpdateException { InnerException: SqlException { Number: 2601 or 2627 } } =>
                (409, "Conflict", "A record with the same unique value already exists (e.g. serial number)."),
            DbUpdateException { InnerException: SqlException { Number: 547 } } =>
                (409, "Conflict", "This record is linked to other data."),
            _ => (500, "Server error", env.IsDevelopment() ? exception.Message : "An unexpected error occurred.")
        };

        if (status == 500) logger.LogError(exception, "Unhandled exception");
        else logger.LogWarning("{Status} {Title}: {Detail}", status, title, detail);

        httpContext.Response.StatusCode = status;
        return await problemDetailsService.TryWriteAsync(new ProblemDetailsContext
        {
            HttpContext = httpContext,
            Exception = exception,
            ProblemDetails = new ProblemDetails { Status = status, Title = title, Detail = detail }
        });
    }
}

Every error now reaches the clients in one standard shape (ProblemDetails, RFC 9457):

2.0 Modern Angular concepts

Angular has changed a lot since 2023. Older tutorials use NgModules, *ngIf/*ngFor, constructor injection and class-based guards/interceptors. Today's style:

2.4 Error helper

import { HttpErrorResponse } from '@angular/common/http';

// Turns any HTTP error (including ProblemDetails) into one readable sentence
export function getErrorMessage(err: unknown): string {
  if (err instanceof HttpErrorResponse) {
    if (err.status === 0) return 'Cannot reach the server. Is the API running?';
    const body = err.error;
    if (body?.errors) return Object.values(body.errors).flat().join(' ');   // validation errors
    if (body?.detail) return body.detail;
    if (body?.title) return body.title;
    return err.message;
  }
  return 'Something went wrong.';
}

2.5 Services

core/services/auth.service.ts

import { computed, inject, Injectable, signal } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { Router } from '@angular/router';
import { Observable, tap, throwError } from 'rxjs';
import { environment } from '../../../environments/environment';
import { AuthResponse, LoginRequest, RegisterRequest } from '../models/auth.model';

const STORAGE_KEY = 'auth';

@Injectable({ providedIn: 'root' })   // one shared instance for the whole app
export class AuthService {
  private http = inject(HttpClient);
  private router = inject(Router);
  private baseUrl = `${environment.apiUrl}/auth`;

  // The single source of truth for "who is logged in"
  private authState = signal<AuthResponse | null>(this.readStorage());

  readonly user = computed(() => this.authState()?.user ?? null);
  readonly isLoggedIn = computed(() => this.authState() !== null);
  readonly isAdmin = computed(() => this.user()?.roles.includes('Admin') ?? false);

  get accessToken(): string | null {
    return this.authState()?.accessToken ?? null;
  }

  login(request: LoginRequest): Observable<AuthResponse> {
    return this.http.post<AuthResponse>(`${this.baseUrl}/login`, request).pipe(tap((res) => this.save(res)));
  }

  register(request: RegisterRequest): Observable<AuthResponse> {
    return this.http.post<AuthResponse>(`${this.baseUrl}/register`, request).pipe(tap((res) => this.save(res)));
  }

  refresh(): Observable<AuthResponse> {
    const refreshToken = this.authState()?.refreshToken;
    if (!refreshToken) return throwError(() => new Error('No refresh token'));
    return this.http
      .post<AuthResponse>(`${this.baseUrl}/refresh`, { refreshToken })
      .pipe(tap((res) => this.save(res)));
  }

  logout(): void {
    const refreshToken = this.authState()?.refreshToken;
    if (refreshToken) {
      // Tell the API to revoke the refresh token; ignore failures (we log out locally anyway)
      this.http.post(`${this.baseUrl}/logout`, { refreshToken }).subscribe({ error: () => {} });
    }
    this.clear();
    this.router.navigate(['/login']);
  }

  clear(): void {
    localStorage.removeItem(STORAGE_KEY);
    this.authState.set(null);
  }

  private save(res: AuthResponse): void {
    localStorage.setItem(STORAGE_KEY, JSON.stringify(res));
    this.authState.set(res);
  }

  private readStorage(): AuthResponse | null {
    const raw = localStorage.getItem(STORAGE_KEY);
    return raw ? (JSON.parse(raw) as AuthResponse) : null;
  }
}

About localStorage: it keeps you logged in across page refreshes, and it's common in SPAs. The trade-off is that any script running on the page (an XSS attack) could read it. The stronger alternative is a refresh token in an HttpOnly cookie, a good "next level" exercise. Short access-token lifetimes limit the damage either way.

2.6 Interceptor (token + silent refresh)

core/interceptors/auth.interceptor.ts

import { HttpErrorResponse, HttpInterceptorFn, HttpRequest } from '@angular/common/http';
import { inject } from '@angular/core';
import { catchError, finalize, Observable, shareReplay, switchMap, throwError } from 'rxjs';
import { AuthService } from '../services/auth.service';
import { AuthResponse } from '../models/auth.model';

// Shared between requests so that 5 parallel 401s trigger only ONE refresh call
let refreshInFlight$: Observable<AuthResponse> | null = null;

const AUTH_ENDPOINTS = ['/auth/login', '/auth/register', '/auth/refresh'];

function withToken(req: HttpRequest<unknown>, token: string | null) {
  return token ? req.clone({ setHeaders: { Authorization: `Bearer ${token}` } }) : req;
}

export const authInterceptor: HttpInterceptorFn = (req, next) => {
  const auth = inject(AuthService);
  const isAuthEndpoint = AUTH_ENDPOINTS.some((url) => req.url.includes(url));

  return next(withToken(req, auth.accessToken)).pipe(
    catchError((error: HttpErrorResponse) => {
      // Only handle "token expired" for logged-in users on normal endpoints
      if (error.status !== 401 || isAuthEndpoint || !auth.isLoggedIn()) {
        return throwError(() => error);
      }

      refreshInFlight$ ??= auth.refresh().pipe(
        finalize(() => (refreshInFlight$ = null)),
        shareReplay(1)
      );

      return refreshInFlight$.pipe(
        switchMap((res) => next(withToken(req, res.accessToken))),   // retry with the new token
        catchError((refreshError) => {
          auth.clear();                     // refresh failed → session is over
          window.location.href = '/login';
          return throwError(() => refreshError);
        })
      );
    })
  );
};

How the interceptor works, step by step:

  1. Every request passes through this function.
  2. It attaches the token and sends the request.
  3. If the response is 401, it refreshes the tokens once and retries the original request.
  4. If the refresh also fails, the session is over: it clears storage and sends the user to login.

Components never think about tokens.

export const adminGuard: CanActivateFn = (_route, state) => {
  const auth = inject(AuthService);
  const router = inject(Router);
  if (!auth.isLoggedIn()) return router.createUrlTree(['/login'], { queryParams: { returnUrl: state.url } });
  return auth.isAdmin() ? true : router.createUrlTree(['/products']);
};

Guards are UX, not security. They stop a normal user from seeing the admin pages. The real protection is the API's [Authorize(Roles = "Admin")], because anyone can edit JavaScript in their own browser.

import { Component, computed, inject, OnInit, signal } from '@angular/core';
import { CurrencyPipe, DatePipe } from '@angular/common';
import { RouterLink } from '@angular/router';
import { ProductService } from '../../../core/services/product.service';
import { CategoryService } from '../../../core/services/category.service';
import { AuthService } from '../../../core/services/auth.service';
import { Category, Product } from '../../../core/models/product.model';
import { getErrorMessage } from '../../../core/utils/error-message';

@Component({
  selector: 'app-product-list',
  imports: [RouterLink, CurrencyPipe, DatePipe],
  templateUrl: './product-list.html',
})
export class ProductList implements OnInit {
  private productService = inject(ProductService);
  private categoryService = inject(CategoryService);
  auth = inject(AuthService);

  // ---- UI state (signals) ----
  products = signal<Product[]>([]);
  categories = signal<Category[]>([]);
  loading = signal(false);
  error = signal('');

  // ---- Query state ----
  search = signal('');
  categoryId = signal<number | null>(null);
  sortBy = signal('');
  sortDir = signal<'asc' | 'desc'>('asc');
  page = signal(1);
  readonly pageSize = 5;
  totalPages = signal(0);
  totalCount = signal(0);

  pages = computed(() => Array.from({ length: this.totalPages() }, (_, i) => i + 1));

  ngOnInit() {
    this.categoryService.getAll().subscribe((c) => this.categories.set(c));
    this.load();
  }

  load() {
    this.loading.set(true);
    this.error.set('');
    this.productService
      .getPaged({
        search: this.search(),
        categoryId: this.categoryId(),
        sortBy: this.sortBy(),
        sortDir: this.sortDir(),
        page: this.page(),
        pageSize: this.pageSize,
      })
      .subscribe({
        next: (result) => {
          this.products.set(result.items);
          this.totalPages.set(result.totalPages);
          this.totalCount.set(result.totalCount);
          this.loading.set(false);
        },
        error: (err) => {
          this.error.set(getErrorMessage(err));
          this.loading.set(false);
        },
      });
  }

  onSearch(value: string) {
    this.search.set(value.trim());
    this.page.set(1);   // new search → back to page 1
    this.load();
  }

  onCategoryChange(value: string) {
    this.categoryId.set(value ? Number(value) : null);
    this.page.set(1);
    this.load();
  }

  sort(column: string) {
    if (this.sortBy() === column) {
      this.sortDir.set(this.sortDir() === 'asc' ? 'desc' : 'asc');
    } else {
      this.sortBy.set(column);
      this.sortDir.set('asc');
    }
    this.load();
  }

  sortIcon(column: string) {
    return this.sortBy() !== column ? '' : this.sortDir() === 'asc' ? '▲' : '▼';
  }

  goToPage(page: number) {
    if (page < 1 || page > this.totalPages()) return;
    this.page.set(page);
    this.load();
  }

  delete(product: Product) {
    if (!confirm(`Delete "${product.productName}"?`)) return;
    this.productService.delete(product.productId).subscribe({
      next: () => {
        // If we deleted the last item on this page, step back one page
        if (this.products().length === 1 && this.page() > 1) this.page.set(this.page() - 1);
        this.load();
      },
      error: (err) => this.error.set(getErrorMessage(err)),
    });
  }
}

import { Component, computed, inject, input, OnInit, signal } from '@angular/core';
import { NonNullableFormBuilder, ReactiveFormsModule, Validators } from '@angular/forms';
import { Router, RouterLink } from '@angular/router';
import { ProductService } from '../../../core/services/product.service';

@Component({
  selector: 'app-product-form',
  imports: [ReactiveFormsModule, RouterLink],
  templateUrl: './product-form.html',
})
export class ProductForm implements OnInit {
  // Filled automatically from the route "products/:id/edit" (withComponentInputBinding)
  id = input<string>();

  private fb = inject(NonNullableFormBuilder);
  private productService = inject(ProductService);
  private categoryService = inject(CategoryService);
  private router = inject(Router);

  isEdit = computed(() => !!this.id());
  categories = signal<Category[]>([]);
  imagePreview = signal<string | null>(null);
  saving = signal(false);
  uploading = signal(false);
  error = signal('');

  form = this.fb.group({
    productName: ['', [Validators.required, Validators.maxLength(100)]],
    manufacturingDate: [new Date().toISOString().slice(0, 10), Validators.required],
    serialNo: ['', [Validators.required, Validators.maxLength(50)]],
    imageFileName: this.fb.control<string | null>(null),
    isAvailable: [true],
    categoryId: [0, Validators.min(1)],
    price: [0, [Validators.required, Validators.min(0.01)]],
    brands: this.fb.array([this.createBrandGroup()]),
  });

  get brands() {
    return this.form.controls.brands;
  }

  ngOnInit() {
    this.categoryService.getAll().subscribe((c) => this.categories.set(c));

    if (this.isEdit()) {
      this.productService.getById(Number(this.id())).subscribe({
        next: (p) => {
          this.form.patchValue({
            productName: p.productName,
            manufacturingDate: p.manufacturingDate,
            serialNo: p.serialNo,
            imageFileName: p.imageFileName,
            isAvailable: p.isAvailable,
            categoryId: p.categoryId,
            price: p.price,
          });
          // patchValue can't add rows to a FormArray, so rebuild it
          this.brands.clear();
          p.brands.forEach((b) => this.brands.push(this.createBrandGroup(b)));
          this.imagePreview.set(p.imageUrl);
        },
        error: (err) => this.error.set(getErrorMessage(err)),
      });
    }
  }

  createBrandGroup(brand?: Brand) {
    return this.fb.group({
      brandName: [brand?.brandName ?? '', [Validators.required, Validators.maxLength(100)]],
      stock: [brand?.stock ?? 0, [Validators.required, Validators.min(0)]],
    });
  }

  addBrand() {
    this.brands.push(this.createBrandGroup());
  }

  removeBrand(index: number) {
    this.brands.removeAt(index);
  }

  // Step 1 of saving: upload the image immediately, keep the returned file name
  onFileSelected(event: Event) {
    const file = (event.target as HTMLInputElement).files?.[0];
    if (!file) return;
    this.uploading.set(true);
    this.error.set('');
    this.productService.uploadImage(file).subscribe({
      next: (res) => {
        this.form.controls.imageFileName.setValue(res.fileName);
        this.imagePreview.set(res.url);
        this.uploading.set(false);
      },
      error: (err) => {
        this.error.set(getErrorMessage(err));
        this.uploading.set(false);
      },
    });
  }

  isInvalid(path: string) {
    const control = this.form.get(path);
    return !!control && control.invalid && control.touched;
  }

  // Step 2: send the whole form (including imageFileName) as JSON
  onSubmit() {
    if (this.form.invalid) {
      this.form.markAllAsTouched();
      return;
    }
    this.saving.set(true);
    this.error.set('');

    const request = this.form.getRawValue();
    const save$ = this.isEdit()
      ? this.productService.update(Number(this.id()), request)
      : this.productService.create(request);

    save$.subscribe({
      next: () => this.router.navigate(['/products']),
      error: (err) => {
        this.error.set(getErrorMessage(err));
        this.saving.set(false);
      },
    });
  }
}

3.0 Modern React concepts

React is a library for building UI from components. Unlike Angular, it doesn't include routing, HTTP or forms, so teams pick a standard set of libraries:

Need Angular (built in) React (library used here)
Project tooling Angular CLI Vite
Component state Signals useState
Server data (fetch, cache, refetch) Services + signals TanStack Query
Shared app state (logged-in user) AuthService (root singleton) Context (AuthProvider + useAuth)
HTTP + interceptors HttpClient + HttpInterceptorFn Axios + axios interceptors
Routing + guards Router + CanActivateFn React Router + a <RequireAdmin> wrapper component

Dynamic rows FormArray useFieldArray
Lazy loading loadComponent lazy() + <Suspense>

The core ideas:

  1. A component is a function that returns JSX (HTML-like syntax inside TypeScript).
  2. Props go in, state lives inside. When state changes, React re-runs the function and updates the screen.
  3. Hooks (useState, useQuery, useForm, …) give components abilities. Call them only at the top level of a component, never inside if statements or loops.
  4. Server state (data from the API) is not stored in useState. TanStack Query owns it: caching, loading/error flags, refetching after changes.
  5. Data flows down (parent → child through props). Events flow up (the child calls a function the parent passed in, like onSubmit).

import axios from "axios";
import type { AxiosError, InternalAxiosRequestConfig } from "axios";
import { tokenStorage } from "./tokenStorage";
import type { AuthResponse } from "../types/auth";

export const API_URL = import.meta.env.VITE_API_URL;

export const api = axios.create({ baseURL: `${API_URL}/api` });

// ---- Request interceptor: attach the access token ----
api.interceptors.request.use((config) => {
  const token = tokenStorage.get()?.accessToken;
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

// ---- Response interceptor: on 401, refresh once and retry ----
let refreshPromise: Promise<string> | null = null;   // shared, so parallel 401s cause ONE refresh
const AUTH_ENDPOINTS = ["/auth/login", "/auth/register", "/auth/refresh"];

async function refreshAccessToken(): Promise<string> {
  const refreshToken = tokenStorage.get()?.refreshToken;
  if (!refreshToken) throw new Error("No refresh token");
  // Plain axios (not `api`), so this call skips our interceptors
  const { data } = await axios.post<AuthResponse>(`${API_URL}/api/auth/refresh`, { refreshToken });
  tokenStorage.set(data);
  return data.accessToken;
}

api.interceptors.response.use(
  (response) => response,
  async (error: AxiosError) => {
    const original = error.config as (InternalAxiosRequestConfig & { _retry?: boolean }) | undefined;
    const isAuthEndpoint = AUTH_ENDPOINTS.some((url) => original?.url?.includes(url));

    if (error.response?.status !== 401 || !original || original._retry || isAuthEndpoint || !tokenStorage.get()) {
      return Promise.reject(error);
    }

    original._retry = true;   // never retry the same request twice
    try {
      refreshPromise ??= refreshAccessToken().finally(() => {
        refreshPromise = null;
      });
      const newToken = await refreshPromise;
      original.headers.Authorization = `Bearer ${newToken}`;
      return api(original);
    } catch (refreshError) {
      tokenStorage.clear();            // session over
      window.location.href = "/login";
      return Promise.reject(refreshError);
    }
  }
);

import { useState } from "react";
import type { ReactNode } from "react";
import { AuthContext } from "./AuthContext";
import { authApi } from "../api/authApi";
import { tokenStorage } from "../api/tokenStorage";
import type { LoginRequest, RegisterRequest, User } from "../types/auth";

export function AuthProvider({ children }: { children: ReactNode }) {
  // Lazy initial state: read localStorage once, on first render
  const [user, setUser] = useState<User | null>(() => tokenStorage.get()?.user ?? null);

  async function login(request: LoginRequest) {
    const data = await authApi.login(request);
    tokenStorage.set(data);
    setUser(data.user);
  }

  async function register(request: RegisterRequest) {
    const data = await authApi.register(request);
    tokenStorage.set(data);
    setUser(data.user);
  }

  async function logout() {
    const refreshToken = tokenStorage.get()?.refreshToken;
    try {
      if (refreshToken) await authApi.logout(refreshToken);
    } catch {
      // ignore: we log out locally anyway
    } finally {
      tokenStorage.clear();
      setUser(null);
    }
  }

  const isAdmin = user?.roles.includes("Admin") ?? false;

  return <AuthContext value={{ user, isAdmin, login, register, logout }}>{children}</AuthContext>;
}

import type { Product, ProductQuery } from "../types/product";

export default function ProductListPage() {
  const { isAdmin } = useAuth();
  const [query, setQuery] = useState<ProductQuery>({ page: 1, pageSize: 5, sortDir: "asc" });
  const [searchText, setSearchText] = useState("");

  const { data, isPending, isError, error, isFetching } = useProducts(query);
  const { data: categories = [] } = useCategories();
  const deleteProduct = useDeleteProduct();

  // Merge changes into the query; any filter change goes back to page 1
  function updateQuery(changes: Partial<ProductQuery>) {
    setQuery((q) => ({ ...q, page: 1, ...changes }));
  }

  function handleSearch(e: FormEvent) {
    e.preventDefault();
    updateQuery({ search: searchText.trim() });
  }

  function sort(column: string) {
    setQuery((q) => ({
      ...q,
      sortBy: column,
      sortDir: q.sortBy === column && q.sortDir === "asc" ? "desc" : "asc",
    }));
  }

  function sortIcon(column: string) {
    return query.sortBy !== column ? "" : query.sortDir === "asc" ? "▲" : "▼";
  }

  function handleDelete(p: Product) {
    if (confirm(`Delete "${p.productName}"?`)) deleteProduct.mutate(p.productId);
  }

  if (isPending) return <p>Loading products...</p>;
  if (isError) return <div className="alert alert-danger">{getErrorMessage(error)}</div>;

  const pages = Array.from({ length: data.totalPages }, (_, i) => i + 1);

  return (
    <>
      <div className="d-flex justify-content-between align-items-center mb-3">
        <h3 className="mb-0">
          Products <small className="text-muted fs-6">({data.totalCount})</small>
          {isFetching && <span className="spinner-border spinner-border-sm ms-2" />}
        </h3>
        {isAdmin && <Link to="/products/new" className="btn btn-primary">+ New Product</Link>}
      </div>

      <div className="row g-2 mb-3">
        <form className="col-md-6" onSubmit={handleSearch}>
          <div className="input-group">
            <input
              className="form-control"
              placeholder="Search name or serial no..."
              value={searchText}
              onChange={(e) => setSearchText(e.target.value)}
            />
            <button className="btn btn-outline-secondary">Search</button>
          </div>
        </form>
        <div className="col-md-4">
          <select
            className="form-select"
            value={query.categoryId ?? ""}
            onChange={(e) => updateQuery({ categoryId: e.target.value ? Number(e.target.value) : null })}
          >
            <option value="">All categories</option>
            {categories.map((c) => (
              <option key={c.categoryId} value={c.categoryId}>{c.categoryName}</option>
            ))}
          </select>
        </div>
      </div>

      {deleteProduct.isError && <div className="alert alert-danger">{getErrorMessage(deleteProduct.error)}</div>}

      <div className="table-responsive">
        <table className="table table-bordered table-striped align-middle">
          <thead className="table-dark">
            <tr>
              <th>Image</th>
              <th role="button" onClick={() => sort("name")}>Name {sortIcon("name")}</th>
              <th>Serial No</th>
              <th role="button" onClick={() => sort("date")}>Mfg Date {sortIcon("date")}</th>
              <th>Category</th>
              <th role="button" onClick={() => sort("price")}>Price {sortIcon("price")}</th>
              <th>Available</th>
              <th>Brands</th>
              {isAdmin && <th>Actions</th>}
            </tr>
          </thead>
          <tbody>
            {data.items.map((p) => (
              <tr key={p.productId}>
                <td><img src={p.imageUrl} alt={p.productName} width={70} className="img-thumbnail" /></td>
                <td>{p.productName}</td>
                <td>{p.serialNo}</td>
                <td>{new Date(p.manufacturingDate).toLocaleDateString()}</td>
                <td>{p.categoryName}</td>
                <td>{p.price.toLocaleString(undefined, { style: "currency", currency: "USD" })}</td>
                <td>
                  <span className={`badge ${p.isAvailable ? "bg-success" : "bg-secondary"}`}>
                    {p.isAvailable ? "Yes" : "No"}
                  </span>
                </td>
                <td>
                  {p.brands.length === 0 ? (
                    <small className="text-muted">None</small>
                  ) : (
                    p.brands.map((b) => (
                      <div key={b.brandId}>{b.brandName} <small className="text-muted">({b.stock})</small></div>
                    ))
                  )}
                </td>
                {isAdmin && (
                  <td className="text-nowrap">
                    <Link to={`/products/${p.productId}/edit`} className="btn btn-sm btn-warning me-1">Edit</Link>
                    <button className="btn btn-sm btn-danger" onClick={() => handleDelete(p)} disabled={deleteProduct.isPending}>
                      Delete
                    </button>
                  </td>
                )}
              </tr>
            ))}
            {data.items.length === 0 && (
              <tr><td colSpan={9} className="text-center text-muted">No products found.</td></tr>
            )}
          </tbody>
        </table>
      </div>

      {data.totalPages > 1 && (
        <nav>
          <ul className="pagination">
            <li className={`page-item ${!data.hasPrevious ? "disabled" : ""}`}>
              <button className="page-link" onClick={() => setQuery((q) => ({ ...q, page: q.page - 1 }))}>Previous</button>
            </li>
            {pages.map((n) => (
              <li key={n} className={`page-item ${n === data.page ? "active" : ""}`}>
                <button className="page-link" onClick={() => setQuery((q) => ({ ...q, page: n }))}>{n}</button>
              </li>
            ))}
            <li className={`page-item ${!data.hasNext ? "disabled" : ""}`}>
              <button className="page-link" onClick={() => setQuery((q) => ({ ...q, page: q.page + 1 }))}>Next</button>
            </li>
          </ul>
        </nav>
      )}
    </>
  );
}

How the list reacts to changes: when query changes (new page, sort or filter), useProducts(query) gets a new query key. TanStack Query fetches the new data automatically, and keepPreviousData keeps the old rows visible (with a small spinner) until it arrives.

  </StrictMode>

Providers wrap the app so any component inside can use their hooks: useQuery needs QueryClientProvider, useNavigate needs BrowserRouter, and useAuth needs AuthProvider.

StrictMode renders components twice in development, to expose bugs. That's why you may see two identical requests in the Network tab while developing. Production renders once.
