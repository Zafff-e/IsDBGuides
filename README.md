# IsDB Guides: Full-Stack Product App — API → Angular → React

📖 **Read the live online guide here:**

A comprehensive, self-contained interactive guide covering:
- **Part 1:** ASP.NET Core 9 Web API (Clean Architecture, EF Core, JWT Authentication, Repositories, File Uploads)
- **Part 2:** Modern Angular 19+ (Standalone Components, Signals, Reactive Forms, HTTP Interceptors)
- **Part 3:** Modern React 19+ (Vite, TypeScript, React Query / TanStack Query, React Hook Form)
- **Part 4:** Real-world comparison, troubleshooting checklist, and best practices

Features built-in dark/light mode toggle, interactive table of contents, copy-paste code blocks, and mobile-friendly responsive reading experience.
